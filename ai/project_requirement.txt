১ · এই নথি কীভাবে পড়বেন
এই নথিটি দুই স্তরে লেখা। প্রতিটি ফিচারের ব্যাখ্যা ও অ্যালগরিদম বাংলায় — যাতে কোড লেখার আগে কী বানাতে হবে তা পরিষ্কার হয়। তার নিচে একটি ছায়া দেওয়া বাক্সে DEVELOPER INSTRUCTION ইংরেজিতে — যেটি হুবহু কপি করে যেকোনো AI কোডিং টুলে বসানো যায় বা টিকিট হিসেবে ব্যবহার করা যায়।
প্রতিটি ইংরেজি বাক্স স্বয়ংসম্পূর্ণ। শুধু ২ ও ৩ নম্বর অধ্যায় (স্ট্যাক, ফোল্ডার কাঠামো, ডিজাইন টোকেন) একবার পড়ে নিলে যেকোনো একটি বাক্স আলাদাভাবে বাস্তবায়ন করা যায়। ফিচারের নম্বর UI/UX Blueprint-এর কভারেজ ম্যাপের নম্বরের সাথে হুবহু মেলে।

Unit A · Authentication · ফোন যাচাই
Screen: 02
DESCRIPTION
ফোন নম্বর ও ছয় অঙ্কের OTP দিয়ে পরিচয় নিশ্চিত করা। Firebase শুধু পরিচয় দেয় — ব্যবহারকারীর কোনো তথ্য সেখানে জমা হয় না। লগইনের পরে সব কাজ ডিভাইসের IndexedDB-তে চলে।
ALGORITHM — কীভাবে কাজ করে
ব্যবহারকারী +৮৮০ উপসর্গসহ দশ অঙ্কের নম্বর দেন। ক্লায়েন্ট-সাইড যাচাই: ঠিক ১০ অঙ্ক, প্রথম অঙ্ক ১।
Firebase reCAPTCHA verifier তৈরি করে `signInWithPhoneNumber` ডাকা হয়। ফেরত আসা confirmationResult স্মৃতিতে রাখা হয়, কোথাও লেখা হয় না।
ছয়টি আলাদা ইনপুট বক্সে কোড নেওয়া হয়; একটি অঙ্ক দিলে আপনাআপনি পরেরটিতে যায়, ব্যাকস্পেসে আগেরটিতে ফেরে, পুরো কোড পেস্ট করলে ছয় বক্সে ছড়িয়ে যায়।
৬০ সেকেন্ডের কাউন্টডাউন। শেষ হলে 'আবার পাঠান' সক্রিয় হয়। একই নম্বরে পরপর তিনবারের বেশি পাঠানো যাবে না; চতুর্থ চেষ্টায় ১৫ মিনিটের অপেক্ষা।
সফল হলে uid দিয়ে স্থানীয় ডেটাবেস খোলা হয়। প্রথমবার হলে অনবোর্ডিং স্ক্রিন ০৩-এ, নাহলে সরাসরি স্ক্রিন ০৪-এ।
ভুল কোডে ইনপুট বক্সগুলোর নিচে একটি লাইন দেখানো হয়; বক্স খালি হয় না, ব্যবহারকারী শুধু ভুল অঙ্কটি বদলাতে পারেন।
লগআউটে Firebase সেশন শেষ হয়, কিন্তু স্থানীয় ডেটাবেস অক্ষত থাকে। তথ্য মোছার একমাত্র পথ সেটিংসের স্পষ্ট মুছে ফেলা।
DEVELOPER INSTRUCTION (English — copy & paste)
Build phone + OTP authentication using Firebase Phone Auth.
 
FILES
  src/features/auth/PhoneEntry.tsx
  src/features/auth/OtpEntry.tsx
  src/features/auth/auth.store.ts
  src/lib/db.ts   (Dexie instance, opened with the uid)
 
SIGNATURES
  validateBdPhone(raw: string): { ok: boolean; e164?: string; error?: 'LENGTH'|'PREFIX' }
  sendOtp(e164: string): Promise<ConfirmationResult>
  verifyOtp(c: ConfirmationResult, code: string): Promise<{ uid: string }>
 
REQUIREMENTS
- Accept a 10-digit local number with a fixed +880 prefix segment. Reject unless length is exactly 10 and the first digit is 1.
- Six separate single-character inputs. Auto-advance on entry, back-navigate on backspace, and distribute a 6-character paste across all boxes.
- 60-second resend countdown. Cap at 3 sends per number per 15 minutes; the 4th attempt shows a wait message and disables the button.
- On success, open the Dexie database keyed to the uid. Route first-time users to screen 03 and returning users to screen 04.
- Logout ends the Firebase session but MUST NOT clear IndexedDB.
- All strings from i18n (bn primary). No user data is written to Firebase — identity only.
 
ACCEPTANCE CRITERIA
1. Entering "1712345678" produces e164 "+8801712345678"; entering "0712345678" is rejected with PREFIX.
2. Entering a 9-digit number is rejected with LENGTH and the send button stays disabled.
3. Pasting "482913" into the first OTP box fills all six boxes and enables verify.
4. A wrong code shows the error line while leaving the entered digits in place for correction.
5. Pressing resend three times within 15 minutes disables it and shows the wait message on the fourth.
6. After logout and a fresh login with the same number, all previously saved jobs and income entries are still present.

Feature 1 · মার্কেটপ্লেস তুলনা · Marketplace Comparison
Screen: 06, 07
DESCRIPTION
বড় মার্কেটপ্লেসগুলোর কাঠামোগত পার্থক্য এক জায়গায় — চুক্তি, কাজ পাওয়ার নিয়ম, বিরোধ নিষ্পত্তি, রেটিং, আর টাকা তোলার চ্যানেল। কাঠামোগত তথ্য স্থিতিশীল; ফি ও শতাংশ নয়, তাই সেগুলো আলাদা করে রাখা এবং যাচাইয়ের তারিখসহ দেখানো।
ALGORITHM — কীভাবে কাজ করে
`data/marketplaces.json` থেকে সব মার্কেটপ্লেস পড়া হয়। ফাইলটি হাতে লেখা এবং যাচাই করা; কোনো নেটওয়ার্ক কল নেই।
এক-নির্বাচন অবস্থায় নির্বাচিত মার্কেটপ্লেসের পাঁচটি বিভাগ উল্লম্বভাবে দেখানো হয়: contract, winning, dispute, rating, withdrawal।
দুই-নির্বাচন অবস্থায় একই পাঁচটি বিভাগ দুই কলামের সারণিতে বসে। দুটি কলামের মান আলাদা হলে সারিটিতে হালকা #EDF3FF আভা পড়ে — তুলনাটাই এই স্ক্রিনের কাজ।
প্রতিটি সংখ্যাসূচক মান একটি অবজেক্ট: `{ value, verifiedOn }`। `value` null হলে সংখ্যার জায়গায় TodoChip বসে এবং কোনো অনুমান দেখানো হয় না।
`verifiedOn` তারিখ আজ থেকে ১৮০ দিনের বেশি পুরনো হলে চিপের পাশে একটি অ্যাম্বার বিন্দু বসে।
কার্ডের নিচে স্থির একটি লাইন সবসময় থাকে — সংখ্যা বদলায়, ব্যবহারের আগে নিজে মিলিয়ে নিন।

PLATFORM LIMIT — state this to the team and design around it, do not paper over it.
 
A progressive web app cannot reliably raise a local notification while it is
closed on iOS Safari. Background execution is not granted, and scheduled local
notifications are not available. Android Chrome is better but still subject to
aggressive process termination on low-end devices, which is most of this
market.
 
The design therefore layers three mechanisms and depends on none of them alone:
 
  1. In-app banner  — computed on every app open from the same scheduler
                      rules. This ALWAYS works and is the primary mechanism.
  2. Web Push       — used where the browser supports it and the user has
                      granted permission. Treated as a bonus, never assumed.
  3. Calendar file  — deadlines and document expiry dates can be exported as
                      an .ics file the user adds to their own calendar, which
                      then fires reliably outside the app entirely.
 
Write the UI copy so that nothing promises a notification will arrive. A
deadline card says when something is due; it does not say the user will be
reminded.

Colour roles — লাল কেবল সেটিংসের মুছে ফেলায়; ভায়োলেট কেবল স্ক্রিন ১২, ১৩, ১৪ ও AI নিয়ন্ত্রণে; সবুজ কেবল পূর্ণ অবস্থায়।
Bangla rendering — ৯২% অস্বচ্ছ কাচের উপর ছোট বাংলা লেখা কম দামের অ্যান্ড্রয়েড ফোনে পড়ে দেখুন; যুক্তাক্ষর ভাঙছে কি না তা ইমুলেটরে ধরা পড়ে না।
Accessibility — ৪৮px টাচ টার্গেট, সর্বনিম্ন ১৩px লেখা, সর্বত্র বাংলা অঙ্ক, এবং কোনো অর্থ কেবল রঙে বহন করা হয়নি।
Language — অ্যাপ জুড়ে কোথাও দাম, প্ল্যান, স্টোর ব্যাজ, ইনস্টল বা ডাউনলোডের ভাষা নেই; কোনো সংযোগ-সংক্রান্ত ব্যাজ বা মোডের নাম নেই।
